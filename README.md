# InventaMX

Sistema de Gestión de Inventarios y POS (Punto de Venta) diseñado para profesionalizar microempresas en México.

## Estado del Proyecto
**Fase Actual:** 0 - Ideación y Gobernanza
**Estatus:** En definición de alcance y viabilidad.

## Declaración del Problema
Los dueños de microtiendas pierden entre $2,500 y $6,000 MXN mensuales por falta de control de inventarios y gestión manual (libreta). El objetivo es validar si una solución digital accesible puede revertir estas pérdidas.

## Estructura del Repositorio
El desarrollo sigue un ciclo de vida (SDLC) estricto. Actualmente solo contiene documentación de gobernanza:
- `/Fase_0_Ideacion_Gobernanza`: Definición del problema, Lean Canvas y actas de aprobación.
